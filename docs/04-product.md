# Product Definition (MVP)

## Product Goal

Build a personal injury journal that helps users organize their healthcare journey by tracking injuries, symptoms, treatments, and medical events in one place.

---

## MVP Scope

The first version focuses on:

- Creating and managing injury profiles.
- Recording healthcare journey events.
- Viewing a chronological injury timeline.
- Keeping personal medical information organized.

---

## Core Features (Must Have)

### Authentication

Users can:

- Create an account.
- Log in and log out.
- Access only their own data.

### Injury Management

Users can:

- Create an injury profile.
- Edit injury information.
- Delete an injury.
- View their injuries.

Example:

```
Left hip pain
Started: 2022
Status: Under investigation
```

### Timeline Events

Users can record:

- Symptoms.
- Doctor visits.
- Imaging/tests.
- Treatments.
- Rehabilitation activities.
- Medication history.

### Timeline View

Users can:

- View their injury history chronologically.
- Understand what happened and when.

### Dashboard

Users can:

- View their injuries.
- See recent activity.
- Quickly add new events.

---

## Out of Scope (Not MVP)

The first version will not include:

- AI-generated medical summaries.
- Diagnosis or treatment recommendations.
- Document uploads.
- Healthcare provider directory.
- Appointment booking.
- Mobile application.
- Health system integrations.

---

## Future Versions

### Version 2

- Upload medical documents.
- Generate patient summaries.
- Export healthcare history.
- Add better search and filtering.

### Version 3

- Healthcare provider discovery.
- Healthcare navigation features.
- Appointment preparation tools.
- Translation support.

---

## MVP Success Criteria

The MVP is successful if a user can:

- Create an account.
- Create an injury profile.
- Record symptoms and treatments.
- Add medical events.
- View a complete injury timeline.
- Use the information to better communicate with healthcare professionals.
