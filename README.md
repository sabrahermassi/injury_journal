# injury_journal

A full-stack application for organizing and tracking a personal injury journey.

## Overview

Injury Journal helps people with chronic injuries organize their medical history, track symptoms, record treatments, and create a timeline they can use to better communicate with healthcare professionals.

## Problem

People with chronic injuries often have information scattered across:

- medical reports
- doctor visits
- treatment notes
- personal notes

This makes it difficult to understand their journey and explain their history clearly.

## Goal

Build a tool that allows users to:

- create injury profiles
- track symptoms
- document treatments
- maintain a timeline of their medical journey

## Status

🚧 Project is currently in development.

## Tech Stack

Planned:

- Frontend: React
- Backend: Node.js + Express
- Database: PostgreSQL
- Authentication: JWT
