# Injury Journal — Frontend

Next.js (App Router) + React dashboard for the Injury Journal app.

See the [project root README](../README.md) for full setup instructions, API reference, and architecture, the [project root CLAUDE.md](../CLAUDE.md) for a directory/convention overview, and [UI_GUIDE.md](./UI_GUIDE.md) for UI/styling conventions before adding or changing components.

Quick start:

```bash
npm install
# .env.local should set NEXT_PUBLIC_API_URL (defaults to http://localhost:3001)
npm run dev
```
